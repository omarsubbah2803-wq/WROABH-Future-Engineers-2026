# CAD

This folder contains the mechanical design files and models related to our WRO Future Engineers 2026 vehicle.

The CAD documentation is intended to show the mechanical structure of the vehicle, including the chassis, steering mechanism, drivetrain and other custom mechanical parts.

Final CAD files will be added when available.

## Included Design Areas

- Chassis
- Parallel steering mechanism
- Motor drive system
- Gear train
- Sensor mounts
- Camera mount
- Other mechanical components

The files in this folder should represent the actual competition vehicle and its mechanical design.
