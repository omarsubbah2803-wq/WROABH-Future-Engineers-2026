# Development History

## Engineering Process

Our project follows an iterative engineering process:

Plan → Build → Test → Improve

The purpose of documenting development is to show how the current vehicle was reached rather than presenting only the final result.

## Previous Concept

During development, we considered an earlier vehicle concept with a more differential-style approach to propulsion.

That concept was different from the mechanical architecture of the current vehicle.

## Why We Changed the Design

The WRO Future Engineers 2026 rules require a four-wheeled vehicle with one driving axle and one steering actuator.

The rules also do not allow a differential-wheeled base or an electronic differential using one motor per side.

Because of these requirements, the previous architecture was not selected as the final competition design.

## Current Design

The current vehicle uses:

- Four wheels
- Mechanically coupled propulsion
- Dedicated steering
- Parallel steering
- EV3 controller
- Pixy2 camera
- Ultrasonic sensor

## Parallel Steering Decision

We considered different steering geometries during development.

The current vehicle uses parallel steering because its mechanical linkage is simpler to implement with the LEGO Technic components available to our team.

The steering actuator moves the linkage, which transfers movement to the steering wheels.
